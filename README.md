## Description

A small multi-page website with JavaScript tasks about the DOM and events. Every page has the same navbar, so you can switch between the parts.

| Page | Tasks |
|------|-------|
| `index.html` | Part 1: Task 0 (first script, console.log, alert) and Task 1 (variables and operators) |
| `dom.html` | Part 2: Task 2 (change text), Task 3 (change styles), Task 4 (add/remove list items) |
| `events.html` | Part 3: Task 5 (mouse events), Task 6 (keyboard events), Task 7 (calculator) |
| `todo.html` | Part 4: Task 8 (to-do app) |

Other files: `style.css` (styles for all pages), `part1.js`, `dom.js`, `events.js`, `todo.js` (one script per page).

## How to run

1. Download or clone the repository.
2. Open `index.html` in a browser (no server or install needed).
3. Press F12 and open the Console tab to see the output from Part 1.
